Start with a model

Drop an STL file anywhere on this window, or:

  1. Choose the job at the top of the panel: augment an object, or print a model as foam.
  2. Set the model's parameters in its folder.
  3. Augmenting: press Select Foam Area, drag over the model, then Save Toolpath G-Code. Printing as foam: press Slice Plate.
